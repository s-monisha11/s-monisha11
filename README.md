### 📷 Quality-Guided Sparse 3D Reconstruction

A team Computer Vision project that reconstructs camera positions and a coloured sparse 3D point cloud from overlapping images using an incremental Structure-from-Motion pipeline. We used feature matching, geometric verification, triangulation, camera registration, and bundle adjustment, then tested how image quality and camera selection affect the results. The final pipeline registered 11 of 14 cameras on the ETH3D Pipes dataset and produced 1,629 filtered 3D points.

`Python` `OpenCV` `SIFT/ORB` `Structure-from-Motion` · [Project repository](https://lnkd.in/gUREGZr8)
